# Алгоритм Хаффмана

Проект реализует сжатие и восстановление данных с использованием алгоритма Хаффмана. Поддерживается работа с текстовыми и бинарными файлами.

## Структура программы

- `Huffman.java` — основной класс с точкой входа и пользовательским интерфейсом.
- `Encoder.java` — реализация процедуры кодирования файла.
- `Decoder.java` — реализация процедуры декодирования файла.
- `Node.java` — вспомогательный класс узла дерева Хаффмана, реализующий `Comparable` и `Serializable`.

## Требования
- Установленный JDK версии 8 или выше.
- Компилятор `javac` и среда выполнения `java`.

## Сборка и запуск

1. Убедитесь, что установлены `javac` и `java`:
 ```bash
 java -version
 javac -version
 ```


2. Поместите все .java файлы в одну директорию и выполните компиляцию:
  ```bash
  javac *.java
  ```

3. Запустите программу
  ```bash
java Huffman
```

4. В консоли:  
Выберите режим: encode или decode.  
Укажите имя входного файла.  
Укажите имя выходного файла.  

Пример для кодирования:
```
Enter mode (encode/decode): encode
Enter input file name: input.txt
Enter output file name: output.huff
```

## Структура закодированного файла
Закодированный файл имеет текстовый формат и состоит из трёх частей:

**Заголовок:** количество уникальных байтов (целое число).  
**Таблица частот:** N строк вида <код_байта>:<частота>, где код — число от 0 до 255.  
**Закодированные данные:** одна строка, содержащая последовательность битов (0 и 1).

Пример содержимого закодированного файла:
``` 
3
49:10
50:5
51:5
000000000010101111111111
```
